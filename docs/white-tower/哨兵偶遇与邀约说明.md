# 哨兵偶遇与邀约 · 2026-10-17

在 C 盘修改版接入哨兵社交事件，继续使用原地图、排班、年历、人物档案和剧情选择。累计改动18个已有源文件、新增82个源文件。D盘原卡及源码未改写。

## 偶遇

地图完成一次地点行动后，有机会弹出“哨兵偶遇”。候选人只取自已接诊档案，要求已治疗大于0、污染不高于65；不把待诊陌生人当熟人，也不创建新人物。

弹窗显示姓名、等级、精神体，以及与当前街区相符的相遇片段。玩家可选“聊几句近况”（信赖最多+1）或“点头致意，继续赶路”（关系不变），均不额外占用时段。以前自动增加信赖的随机熟人文本已替换为这一流程。

普通浏览建筑不会触发。判定使用游戏天数、原行动时段和地点的固定种子，概率35%。与原探索事件共用每天一次的途中事件限制，未参加的当地节庆事件优先；同一人物4个游戏日内不重复偶遇。已接受邀约但尚未赴约的人不会同时成为随机偶遇对象。

## 邀约

只在首次进入休息日地图、尚未使用上午时段时检查一次。正在治疗、生成剧情、查看其他弹窗或购物时不会打断。旧档当天已经行动过，则从下个休息日开始。

- 邀请人除满足偶遇条件，还要求信赖至少20；同一人邀约冷却6个游戏日。
- 普通日邀约概率35%，节庆日75%，每天至多一份。检查结果和邀请均存档，拒绝或刷新后不重掷。
- 普通活动有庭园散步、书店闲逛、咖啡馆小坐、温室看花、场边观赛。节庆活动直接使用年历中当天节庆及其开放地点。
- 弹窗显示“某某向你发出邀请”、活动、地点、可参加时间和免费规则。可接受或婉拒；拒绝不扣关系，不自动请求模型。
- 接受只确认计划，时段、地点变量和资源不变。地图会定位邀请地点，原“坐下休息”替换为“参加活动”。其他地点仍可以正常休息。
- 接受后可自由安排当天路线。地图下方可通过“前往活动”重新定位。夏夜星芒要求晚上参加，上午/下午按钮显示“晚上开始”并禁用。
- 实际参加才占1个时段，免费，恢复最多15精力，信赖最多+2、好感最多+1；不预设恋爱或身体接触。结果按实际数值变化记录。
- 完成后恢复普通休息按钮，不可重复领取奖励；节庆邀约同步记录年度节庆足迹，避免再弹同一节庆的参与奖励。赴约也占当天途中事件名额。
- 当天未参加的邀请到下一天过期，不扣关系值。参加考核或用完三个时段后不能额外赴约。

## 存档和剧情

新状态在 `世界.生活.社交`，包含检查日、今日邀约、邀约记录、偶遇日、偶遇记录、待偶遇。旧档通过Schema默认值补齐，不修改人物身份、关系和原进度。未处理的弹窗可从保存的数据恢复；重复提交、过期回应不重复结算。

已有MVU保护会保留前端维护的整个 `世界.生活`，模型不能覆盖邀请、待处理事件或冷却记录。C盘世界书规则也已补充对应只读说明；D盘PNG内嵌世界书本轮未改写。

相遇或赴约结算后仍使用“开启剧情 / 继续探索”的现有选择。只有玩家要求展开剧情时才调用模型；提示要求沿用已接诊档案、不补发奖励、不神化治疗关系、不自动认定恋爱。
