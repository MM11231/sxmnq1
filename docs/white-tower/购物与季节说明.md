# 白塔购物、背包与季节差分 · 2026-10-14

当前源码在 `白塔卡源`，酒馆原地址继续从本目录提供前端和变量结构脚本。D 盘原源码、角色卡 PNG、世界书和真实聊天未被覆盖。

## 地图

城区地图从现有 `世界.季节` 读取配色：春季嫩绿与粉色花冠，夏季浓绿，秋季暖棕与橙色树冠，冬季浅色积雪地面、树冠和屋顶雪边。道路保持深色以便辨认，选中建筑仍可切换色块/线稿。天气粒子继续读取同一份天气数据。

## 购物与背包

- 商业区七家店的地点详情提供“逛商店”：咖啡馆、书店、超市、装备工坊、酒吧、食堂、深夜食堂，共 20 件预设商品。
- 每页三件，先选择数量，再统一结账。首次在同店当日结账占一个休息日时段，补买不占时段；浏览不收费。金钱不足、考核中、值班日或没有首次到店所需时段时不能购买。结账前统一校验，失败不会部分扣款或入包。
- 背包在值班日和休息日都可打开。物品按 id 堆叠，最多 60 种，每种 99 件。
- 补给恢复治疗精力，每天最多使用两份；满精力时不消耗物品。考核或其他忙碌操作中不可使用。
- 背包物品可送给已在哨兵档案中的人物，每位哨兵每天一次，消耗一份，好感 +2、信赖 +1，上限 100。普通道谢文本由前端显示，不自动宣告恋爱关系，不发送剧情请求。
- 购物、使用、赠礼有最近 12 条记录，并进入当日结算。日限制根据游戏天数判断，跨天自动恢复。

## 定制礼物与 API

商店内“定制礼物”使用酒馆助手的 `generateRaw`，沿用玩家已连接的酒馆 API。请求只包含商店名称、设计偏好和生成格式要求，静默生成，不带聊天历史、不新建聊天楼层。

生成结果仅允许 emoji、名称、简短描述。结果可编辑，保存设计免费；确认购买统一 80 金。模型不能设置价格、属性、疗效或赠礼收益。也可完全手动填写。最多保存 24 款设计，每款保持独立 id。

请求失败显示可重试提示；支持取消、关闭时取消和 45 秒超时。无酒馆 API 的独立预览会提示使用手动填写。API 参数、解析及取消经过模拟响应检查，本次未调用玩家真实模型账户，因此不代表真实提供方连接已验证。

## 存档和维护

`src/sxmnq/schema.ts` 新增带默认值的 `购物` 字段，旧存档补为空背包，不影响现有角色数据。`购物/schema.ts` 定义持有物、定制设计、日限制与记录。`购物/规则.ts` 集中处理所有扣款、堆叠、使用、赠礼和定制定价。

前端和 `src/哨向模拟器/脚本/变量结构/index.ts` 使用同一份 Schema。变量更新回调保留旧 `购物` 值，避免模型回复抹掉背包或重复结算。`build.mjs` 同时构建界面、预览和该脚本；两个服务已改为提供 C 盘新版变量结构。修改版世界书规则保存在源码，供下次正式导出合并；当前 D 盘原卡世界书不变，运行时保护由新版变量脚本执行。

`原文件指纹.json` 现在记录 10 个原文件，`新增界面文件.json` 记录 71 个新增文件。`integrate-commerce.mjs` 是本次接入脚本，后续修改直接编辑源码。重新生成建筑时，`generate-building-art.mjs` 会保留购物模块的新增清单。
