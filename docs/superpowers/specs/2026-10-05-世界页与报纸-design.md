# 世界页与报纸 · 设计

2026-10-05

## 1. 为什么做

两件事凑到一起：

1. **诊所页信息太少**。它现在只有 名称/等级/名声/精神力/姓名/金钱/床位/气氛/日期·时段，
   一眼看完是优点，但看第二眼就没东西了。
2. **玩家要「世界是活的」**。参考白塔旧卡的 `[initvar]变量初始`
   （`世界.当前时间/当前地点/当前天气/今日占卜/今日八卦`、`主线任务.当前章节/…`）。

第 1 期（双语折叠）是另一码事 —— 它是**玩家当下正在被烦的 bug**，先修。

## 2. 硬约束（玩家给的，逐条落到设计里）

### 2.1 世界不围着玩家转

> 「不要写关于求诊的问题，容易造成媚u …… 最开始还是小诊所的时候有个报纸求诊
> 很出戏也很尴尬，像是硬夸。」

这条是本设计里最重的一条，它同时否掉了一个很自然的设计（拿存档数据派生新闻）：

- **报纸池子里的条目跟玩家八竿子打不着**。四大特区的政治、航线、物价、讣告、广告 ——
  世界自顾自运转才好看。
- **报纸自发提到诊所 = 跟名声挂钩的罕见事件**。名声是个位数时一个字都不提；
  等到确实是本区一号人物了才自然出现。这样「上报」本身是进度反馈，不是开局就发的奖状。
- 任何形式的「因为你来了所以大家都很高兴」都不写。

### 2.2 报纸不必强绑定剧情

> 「内容不一定非要强绑定，可以有关也可以没有关，核心在于增强用户游玩的沉浸性」

所以报纸的主体是**按日期定种抽出来的氛围内容**（零 token），AI 供稿是可选的点缀。

### 2.3 投稿是玩家的动作，不是游戏的赏赐

> 「上报需要花钱，如果是宣传诊所的可以加名声，但我们也可以让user自由发挥写点东西」
> 「不，不要有免费的版面。」

- 投稿**一律花钱**，没有免费版面。
- 「宣传诊所」版面加名声；其余版面纯沉浸，文字玩家自己写。
- 早期 `金钱: 0`（实测存档）就是登不了报 —— 这是设计要的，想打广告先挣到钱。

### 3.1 改版（同日，第 4 期做完之后）

四期都实现完之后玩家提了一次返工：

> 「把天气和塔罗牌什么的移到诊所界面，世界界面只留下新闻，以及这份投稿界面的广告和宣传
> 是不是重复了，讣告做的也意义不明，新闻模块改成社会区块，学术科技区块和趣闻区块好了」

四条改动，各有一处判断：

1. **天气搬去诊所页**。查下来诊所页**本来就有一行** `季节 · 天气 · 温度`（§5.2 加的），
   世界页那行是重复的 —— 所以这不是「搬家」，是**删掉世界页那份**。
2. **占卜搬去诊所页**。世界页从此只剩两样东西：世界一角 + 报纸。搬的过程中发现一个潜伏的
   bug：世界页传给 `起一卦` 的是 `诊所.床位`，而这个字段早在床位改成派生值时就删了
   （`2026-09-28-家园与家具-design.md` §7.1）—— 也就是说解读里那句「床位」**一直传的是
   `undefined`**，从来没算对过。诊所页用它自己的 `床位` 派生值，顺手修掉了。
3. **六个版面收成五个**。原来那六版里有三版在说同一件事（要闻 / 经济·军事 / 社会 都在报
   「世界在怎么运转」）。新的分法不问「这条新闻属于哪个领域」，问**读者为什么读它**：
   `社会`（世界在怎么运转）/ `学术·科技`（白塔在琢磨什么）/ `趣闻`（普通人今天在干什么）
   + `讣告` + `分类广告`。旧的「要闻」「经济·军事」条目**打散并进**新区块，没有丢。
4. **「宣传」和「广告」分开**。两个按钮看着是同义词，价格却差三倍。查下来它们是**两件不同的
   商品**，不是一件事的两个名字：`宣传诊所` 是「我要让人知道这家诊所」→ 加名声；`广告` 是
   「我要转让一台恒温箱」→ 不加名声。两者都印在分类广告版上，**差别在买的是什么，不在位置**。
   所以改法是**改名 + 把名声差写在按钮说明里**，而不是删掉一个（玩家要的「自由发挥」需要两者都在）。
5. **讣告从价目表下架**。玩家说「讣告做的也意义不明」—— 追下去，问题不在讣告本身，在于
   **让玩家花钱买**：他手里没有可以悼念的人，点「悼念与追思」只会问「我该写谁」。
   所以**报纸照常登讣告**（那 16 条留在池子里，真报纸本来就有这一版），
   只是**玩家买不到这一版**。这是一处判断，玩家可以推翻。

## 4. 第 1 期 · 双语折叠

### 4.1 现状（实测）

新预设（`哨向模拟器 - 2026-10-05`）一条 5111 字的消息，`切块` 切成 6 块，挑块是对的：

```
折起 1252 story_driver   推理
摊开 1640 story_scene    剧情 —— 但 汉字 921 / 假名 517
折起  149 memory_log /  286 wlog /  12 affinity /  6 acg_think
```

`<story_scene>` 内部是**逐行双语镜像**：

```
☆‹錆びついたシャッターが上がりきると、外の冷たい空気が…›
生锈的卷帘门彻底升起，外面的冷空气与消毒液的味道混合在一起，流进了候诊室。
```

块级判据管不到行级，所以两轨一起渲染了。

### 4.2 判据：中文里不会出现的字符

**不能用「汉字少」判外语** —— 日文行里汉字一大把（`錆びついた…` 十几个汉字）。
第一版探针就是这么写的，报回来「外语行 0 行」，恰恰证明了它是坏仪表。

判据改成**中文里不会出现的字符**：

| 字符类 | 码位 | 说明 |
|---|---|---|
| 平假名/片假名 | `぀-ゟ` `゠-ヿ` | 日文 |
| 谚文 | `가-힯` `ᄀ-ᇿ` | 韩文 |
| 西里尔 | `Ѐ-ӿ` | 俄文 |
| 阿拉伯/希伯来/泰/天城文 | 各自区段 | 其他 |

规则（**两条取或**，都要求该行汉字极少）：

1. 该行含 **≥2 个非拉丁外语字符** → 外语行。这一条管日/韩/俄 ——
   它们汉字多不多都无所谓。
2. 该行 **汉字 = 0 且拉丁字母 ≥ 8** → 外语行。这一条管英文。
   阈值 8 是防「OK」「B 级」这种中文里正常夹的英文。

### 4.3 安全闸：只在双语时折

**整块要是没有成规模的中文轨，一个字都不折。**

不设这条，纯英文预设（或者英文玩家）打开界面会发现整篇正文被折起来 —— 比不折糟得多，
而且不报错。判据：摊开那块里，「中文行」的汉字总数 < 整块汉字总数的 30% 时，**整个折叠关掉**。

### 4.4 形态（玩家选的：逐句折在译文旁）

译文读完，下一行挂一条细折叠：

```
铜铃又响了一声。
▸ 原文 · 19 字

这次进来的不是病人，是白塔的传令官。
▸ 原文 · 24 字
```

配对规则：**一条外语行归属于它后面最近的一条中文行**。没有后续中文行的孤行，
自己折一条。原文在前、译文在后（源顺序）也要认 —— 那时外语行归属于它**前面**最近的中文行。

### 4.5 落点

- `正文适配.ts`：新增 `片段` 类型与 `切片段(块)`，`显示块` 增加 `片段: 片段[]`。
  折起的块 `片段` 只有一段。
- `适配表` 增加 `折外语: z.boolean().default(true)`，玩家能关。
- `主界面/App.vue`：摊开那块从 `分段(块.内容)` 改渲染 `块.片段`。
- `假数据.ts`：`message_id: 3` 换成**双语预设的真实骨架**当活体回归。

## 5. 第 2 期 · 变量扩展 + 诊所页

### 5.1 加什么

实测你那份新预设**已经在输出这些了**，加字段几乎不增加它的负担：

```
<story_driver>  【当前时间】: 1年霜降月1日(秋)(无)/07:30(朝)/星期一｜天气(雾)
                【世界主线】: 霜降月初日，各大军区与财团区域的伤员开始例行或隐秘地…
<wlog>          【世界主线】…  ｜进行中
                【平行线事件】- 极东商贸区管理局｜下属雇佣兵｜[情报]…｜当前状态:…
```

`世界` 增：

```ts
时刻:       z.string().prefault(''),   // "07:30"
星期:       z.string().prefault(''),   // "星期一"
季节:       z.string().prefault(''),   // "秋"
天气:       z.string().prefault(''),   // "雾"
温度:       z.string().prefault(''),   // "偏冷" —— 可空
世界主线:   z.string().prefault(''),   // 一句话，世界页顶部显示
近期事件:   z.array(近期事件形状).prefault([]),   // 平行线事件，最多留 5 条
```

`近期事件形状`：`{ 名称, 状态, 说明 }`，全都 `prefault('')`。

**每个字段都要有 prefault**：MVU 每次 parse 的是整份 `stat_data`，缺一个字段就整体
safeParse 失败、整个 store 退回默认值（`util/mvu.ts: if (result.error) return`），
界面上表现成「数据全没了」。

### 5.2 诊所页

补 `时刻 / 天气 / 地点`，**保持一眼看完的密度** —— 用户要的是「丰富」，不是「变长」。
具体的排布在实现时对着手机宽度（320px）定。

## 6. 第 3 期 · 世界页 + 报纸

### 6.1 版面

主界面从四个标签变五个：`剧情 / 诊所 / 申请 / 家园 / 世界`。
标签条在 320px 宽已经快放不下四个，实现时要再收一档并**在真浏览器里量**（不是估算）。

「世界」页从上到下（§3.1 改版后只剩两块）：

1. **世界一角** —— 一句 `世界主线` + `近期事件`。日期和天气**不在这**（日期在报头上，
   天气在诊所页）。
2. **《白塔日报》** —— 报纸本体。
3. **投稿** —— 折叠着的填表面板。

~~占卜入口~~ —— §3.1 改版后搬到**诊所页**底部。「世界」页从此只管「外面发生了什么」，
「我这间诊所怎么样」全归诊所页。

### 6.2 报纸 = 前端池子 + AI 可选供稿

**内容来源**，按玩家的约束：

| 来源 | 占比 | 定种 | token |
|---|---|---|---|
| 氛围池（代码里） | 主体 | 按 `世界.日期` 定种抽 | 0 |
| AI 供稿（变量） | 社会版第一条，可选 | 只显示 `日期 === 世界.日期` 的 | AI 已经在写 `<wlog>`，几乎免费 |

**氛围池**：`src/sxmnq/报纸/池子.ts`，素材从旧卡世界书 112 条里挖
（四大特区：极北凛冬/极南森海/极东浮岛/极西狂沙，节日、组织、地点）。分版面
（§3.1 改版后的五版，次序即渲染次序）：

- 社会（3 条）· 学术科技（2）· 趣闻（2）· 讣告（1）· 分类广告（2）

`天气` 版整版撤了 —— 天气是诊所页那个格子的事，报纸不必再报一遍。

池子要**大**（现 142 条）——
池子读完了就开始撞重复，而重复的报纸最伤沉浸感，这是这个模块唯一的真实成本。

**定种**：`hash(世界.日期) → 伪随机序列`，同一天刷新多少次都是同一份报。
`世界.日期` 是 AI 写的字符串（实测 `"霜降月第一日"`），只在跨天才变 —— 这正是我们要的。

**AI 供稿**：`世界.报纸供稿: z.array({日期, 标题, 正文}).prefault([])`。
只显示 `日期 === 世界.日期` 的。AI 忘写 = 没有头条，退回池子，**不会空版**；
AI 忘了清理旧条目也没关系，日期对不上就不显示。schema 里截断保留最近 5 条。

供稿**进社会版第一条**（§3.1 改版前是要闻版）。社会版每版 3 条，而供稿另有一个
**比它小的上限 `供稿上限 = 2`** —— 不能直接复用 `每版条数.社会`，那等于让 AI
能把社会版整版写完，池子的内容一条都上不去。AI 是点缀，不是这一版的全部。

### 6.3 投稿

`世界.报纸投稿: z.array({日期, 版面, 标题, 正文, 署名}).prefault([])`。

- **一律花钱**。价格随 `诊所.等级` 涨（D 级也贵，因为开局金钱 0）。
- 可买的版面五档（§3.1 改版后）：`宣传诊所 / 社会 / 学术科技 / 趣闻 / 广告`。
  其中 **只有 `宣传诊所` 加名声**，其余纯沉浸，文字玩家自己写。
- **讣告不在价目表里** —— 玩家买不到这一版，但报纸照常登（见 §3.1 第 5 条）。
- 文字玩家自由写（标题 + 正文 + 署名）。
- **一期（一天）只能登一则** —— 报纸一天就出一期，这个限制天然存在，不需要额外规则。
- 当期的投稿嵌在对应版面里显示；往期的沉到「往期」折叠。
- `版面` 的窄化用 **`z.string()` + `transform`，不是 `z.enum()`**：换成 enum 的话，
  一份躺在旧版面名（`宣传`/`要闻`/`经济`/`讣告`）上的存档加载时整个 `stat_data`
  `safeParse` 失败退回默认值，玩家看到的是「数据全没了」。认不出的名字收窄到 `广告`。
  `schema.test.mjs` 有一条专门盯这个。

### 6.4 媚u 防线（实现时的自检）

报纸池子和 AI 供稿都要过一遍：**任何一条要是把玩家写成了世界的中心，就删掉**。
特别注意：小诊所开业第一天，报纸上不该有它的名字。

## 7. 第 4 期 · 占卜塔罗

- **22 张大阿卡纳** + 正逆位牌义，全部内置在前端（`src/sxmnq/占卜/塔罗.ts`）。
- 按 `世界.日期` 定种抽，**同一天不重抽**。
- 解读 = 牌义 × 当日局势（`精神力` / `诊所.名声` / 在诊人数）。
- 抽完**连解读一起存进变量**，当天不变：

```ts
占卜: z.object({
  已抽于: z.string().prefault(''),   // 日期戳，与 世界.日期 相等就不再抽
  牌:     z.string().prefault(''),
  逆位:   z.boolean().prefault(false),
  解读:   z.string().prefault(''),
}).prefault({}),
```

- 交互是**全屏翻牌层**：点「占卜」→ 盖一层 → 牌背 → 点开翻面 → 显出牌与解读。
- **入口在诊所页底部**（§3.1 改版从世界页搬来）。诊断是「我这个当家人今天运势如何」，
  跟诊所页那堆数字是同一类信息；世界页只留「外面发生了什么」。
  翻牌层是**接管**而非叠层 —— 诊所页那几行在翻牌时全部让位。

## 8. 不做的事

- **不做报纸求诊/招募**。见 §2.1。
- **不做免费版面**。玩家明确否掉。
- **不把报纸内容写进提示词**。它是给人看的沉浸物，不需要 AI 知道。
- **不做玩家发帖/评论**。报纸是单向的。
- **不重构 `生成/` 那一套**。报纸的定种另起一个小 PRNG，但**不复用掷骰的池子逻辑** ——
  两者的定种键和幂等要求不同（掷骰是「日期变了重掷一批并保留已命名的」，报纸是纯派生）。

## 9. 测试

沿用仓库约定：`node xxx.test.mjs`，动态 import 被测的 `.ts`，不引入 vitest/jest。

| 期 | 测试 |
|---|---|
| 1 | `正文适配.test.mjs` 加「双语镜像」组：日文行折起、中文行留着、**纯英文整块一个字不折**、孤行不丢 |
| 2 | `schema.test.mjs` 加新字段的缺省与 clamp |
| 3 | `报纸/装配.test.mjs`：同日期定种两次结果相同、跨日期不同、每版面都非空、池子条目数 ≥120 |
| 4 | `占卜/塔罗.test.mjs`：22 张无重复、同日期同牌、牌义非空 |

每期另配一个**真浏览器探针**（无头 Edge + CDP，`localhost:5501/预览/`）：

| 探针 | 盯什么 |
|---|---|
| `看世界.mjs` | 五个标签在 320px 挤不挤得下、报纸五版、**真填一次投稿表**（扣钱 → 变量 → 报上多一条）、世界一角只剩主线 + 近期事件 |
| `看占卜.mjs` | 翻牌层的**命中测试**（`elementFromPoint` 认得正反两面）、同一天不重抽、跨天重抽、日期空着时禁用 |
| `看诊所.mjs` | 诊所页三行的空值拼接、320px 不横溢 |

`看世界.mjs` 里那两条**阴性**断言（世界一角不含日期、不含天气）是改版的核心，
所以它前面先有两条**阳性**断言（读得到主线、读得到近期事件）证明仪表没瞎。

**阴性断言必须先自检仪表**（仓库既有教训）：报「泄漏 0 个」之前，先喂一个已知泄漏样本
验证探针数得出来。改版这次也踩了一次同类坑 —— 价目表那一块用 `innerText` 读一个
**折叠着的 `<details>`**，读到五个空串：结构断言（「五档」「讣告不在」）在空数组上
**空过**，内容断言集体报错，看起来像文案没写、其实是仪表瞎了。探针读文字必须先把
那一屏展开成玩家看得见的样子。
