# 世界页与报纸 · 设计

2026-10-05

## 1. 为什么做

两件事凑到一起：

1. **诊所页信息太少**。它现在只有 名称/等级/名声/精神力/姓名/金钱/床位/气氛/日期·时段，
   一眼看完是优点，但看第二眼就没东西了。
2. **玩家要「世界是活的」**。参考白塔旧卡的 `[initvar]变量初始`
   （`世界.当前时间/当前地点/当前天气/今日占卜/今日八卦`、`主线任务.当前章节/…`）。

第 1 期（双语折叠）是另一码事 —— 它是**玩家当下正在被烦的 bug**，先修。

## 2. 硬约束（玩家给的，逐条落到设计里）

### 2.1 世界不围着玩家转

> 「不要写关于求诊的问题，容易造成媚u …… 最开始还是小诊所的时候有个报纸求诊
> 很出戏也很尴尬，像是硬夸。」

这条是本设计里最重的一条，它同时否掉了一个很自然的设计（拿存档数据派生新闻）：

- **报纸池子里的条目跟玩家八竿子打不着**。四大特区的政治、航线、物价、讣告、广告 ——
  世界自顾自运转才好看。
- **报纸自发提到诊所 = 跟名声挂钩的罕见事件**。名声是个位数时一个字都不提；
  等到确实是本区一号人物了才自然出现。这样「上报」本身是进度反馈，不是开局就发的奖状。
- 任何形式的「因为你来了所以大家都很高兴」都不写。

### 2.2 报纸不必强绑定剧情

> 「内容不一定非要强绑定，可以有关也可以没有关，核心在于增强用户游玩的沉浸性」

所以报纸的主体是**按日期定种抽出来的氛围内容**（零 token），AI 供稿是可选的点缀。

### 2.3 投稿是玩家的动作，不是游戏的赏赐

> 「上报需要花钱，如果是宣传诊所的可以加名声，但我们也可以让user自由发挥写点东西」
> 「不，不要有免费的版面。」

- 投稿**一律花钱**，没有免费版面。
- 「宣传诊所」版面加名声；其余版面纯沉浸，文字玩家自己写。
- 早期 `金钱: 0`（实测存档）就是登不了报 —— 这是设计要的，想打广告先挣到钱。

## 4. 第 1 期 · 双语折叠

### 4.1 现状（实测）

新预设（`哨向模拟器 - 2026-10-05`）一条 5111 字的消息，`切块` 切成 6 块，挑块是对的：

```
折起 1252 story_driver   推理
摊开 1640 story_scene    剧情 —— 但 汉字 921 / 假名 517
折起  149 memory_log /  286 wlog /  12 affinity /  6 acg_think
```

`<story_scene>` 内部是**逐行双语镜像**：

```
☆‹錆びついたシャッターが上がりきると、外の冷たい空気が…›
生锈的卷帘门彻底升起，外面的冷空气与消毒液的味道混合在一起，流进了候诊室。
```

块级判据管不到行级，所以两轨一起渲染了。

### 4.2 判据：中文里不会出现的字符

**不能用「汉字少」判外语** —— 日文行里汉字一大把（`錆びついた…` 十几个汉字）。
第一版探针就是这么写的，报回来「外语行 0 行」，恰恰证明了它是坏仪表。

判据改成**中文里不会出现的字符**：

| 字符类 | 码位 | 说明 |
|---|---|---|
| 平假名/片假名 | `぀-ゟ` `゠-ヿ` | 日文 |
| 谚文 | `가-힯` `ᄀ-ᇿ` | 韩文 |
| 西里尔 | `Ѐ-ӿ` | 俄文 |
| 阿拉伯/希伯来/泰/天城文 | 各自区段 | 其他 |

规则（**两条取或**，都要求该行汉字极少）：

1. 该行含 **≥2 个非拉丁外语字符** → 外语行。这一条管日/韩/俄 ——
   它们汉字多不多都无所谓。
2. 该行 **汉字 = 0 且拉丁字母 ≥ 8** → 外语行。这一条管英文。
   阈值 8 是防「OK」「B 级」这种中文里正常夹的英文。

### 4.3 安全闸：只在双语时折

**整块要是没有成规模的中文轨，一个字都不折。**

不设这条，纯英文预设（或者英文玩家）打开界面会发现整篇正文被折起来 —— 比不折糟得多，
而且不报错。判据：摊开那块里，「中文行」的汉字总数 < 整块汉字总数的 30% 时，**整个折叠关掉**。

### 4.4 形态（玩家选的：逐句折在译文旁）

译文读完，下一行挂一条细折叠：

```
铜铃又响了一声。
▸ 原文 · 19 字

这次进来的不是病人，是白塔的传令官。
▸ 原文 · 24 字
```

配对规则：**一条外语行归属于它后面最近的一条中文行**。没有后续中文行的孤行，
自己折一条。原文在前、译文在后（源顺序）也要认 —— 那时外语行归属于它**前面**最近的中文行。

### 4.5 落点

- `正文适配.ts`：新增 `片段` 类型与 `切片段(块)`，`显示块` 增加 `片段: 片段[]`。
  折起的块 `片段` 只有一段。
- `适配表` 增加 `折外语: z.boolean().default(true)`，玩家能关。
- `主界面/App.vue`：摊开那块从 `分段(块.内容)` 改渲染 `块.片段`。
- `假数据.ts`：`message_id: 3` 换成**双语预设的真实骨架**当活体回归。

## 5. 第 2 期 · 变量扩展 + 诊所页

### 5.1 加什么

实测你那份新预设**已经在输出这些了**，加字段几乎不增加它的负担：

```
<story_driver>  【当前时间】: 1年霜降月1日(秋)(无)/07:30(朝)/星期一｜天气(雾)
                【世界主线】: 霜降月初日，各大军区与财团区域的伤员开始例行或隐秘地…
<wlog>          【世界主线】…  ｜进行中
                【平行线事件】- 极东商贸区管理局｜下属雇佣兵｜[情报]…｜当前状态:…
```

`世界` 增：

```ts
时刻:       z.string().prefault(''),   // "07:30"
星期:       z.string().prefault(''),   // "星期一"
季节:       z.string().prefault(''),   // "秋"
天气:       z.string().prefault(''),   // "雾"
温度:       z.string().prefault(''),   // "偏冷" —— 可空
世界主线:   z.string().prefault(''),   // 一句话，世界页顶部显示
近期事件:   z.array(近期事件形状).prefault([]),   // 平行线事件，最多留 5 条
```

`近期事件形状`：`{ 名称, 状态, 说明 }`，全都 `prefault('')`。

**每个字段都要有 prefault**：MVU 每次 parse 的是整份 `stat_data`，缺一个字段就整体
safeParse 失败、整个 store 退回默认值（`util/mvu.ts: if (result.error) return`），
界面上表现成「数据全没了」。

### 5.2 诊所页

补 `时刻 / 天气 / 地点`，**保持一眼看完的密度** —— 用户要的是「丰富」，不是「变长」。
具体的排布在实现时对着手机宽度（320px）定。

## 6. 第 3 期 · 世界页 + 报纸

### 6.1 版面

主界面从四个标签变五个：`剧情 / 诊所 / 申请 / 家园 / 世界`。
标签条在 320px 宽已经快放不下四个，实现时要再收一档并**在真浏览器里量**（不是估算）。

「世界」页从上到下：

1. **世界一角** —— 时刻/星期/季节/天气/温度 一行，下面一句 `世界主线`
2. **《白塔日报》** —— 报纸本体
3. **占卜入口** —— 按钮，点开全屏翻牌层（第 4 期）

### 6.2 报纸 = 前端池子 + AI 可选供稿

**内容来源**，按玩家的约束：

| 来源 | 占比 | 定种 | token |
|---|---|---|---|
| 氛围池（代码里） | 主体 | 按 `世界.日期` 定种抽 | 0 |
| AI 供稿（变量） | 头条，可选 | 只显示 `日期 === 世界.日期` 的 | AI 已经在写 `<wlog>`，几乎免费 |

**氛围池**：`src/sxmnq/报纸/池子.ts`，素材从旧卡世界书 112 条里挖
（四大特区：极北凛冬/极南森海/极东浮岛/极西狂沙，节日、组织、地点）。分版面：

- 要闻 · 社会 · 经济/军事 · 讣告 · 分类广告 · 天气

每期每版面抽 1~2 条，条目数按版面定。池子要**大**（目标 ≥120 条）——
池子读完了就开始撞重复，而重复的报纸最伤沉浸感，这是这个模块唯一的真实成本。

**定种**：`hash(世界.日期) → 伪随机序列`，同一天刷新多少次都是同一份报。
`世界.日期` 是 AI 写的字符串（实测 `"霜降月第一日"`），只在跨天才变 —— 这正是我们要的。

**AI 供稿**：`世界.报纸供稿: z.array({日期, 标题, 正文}).prefault([])`。
只显示 `日期 === 世界.日期` 的。AI 忘写 = 没有头条，退回池子，**不会空版**；
AI 忘了清理旧条目也没关系，日期对不上就不显示。schema 里截断保留最近 5 条。

### 6.3 投稿

`世界.报纸投稿: z.array({日期, 版面, 标题, 正文, 署名, 是宣传}).prefault([])`。

- **一律花钱**。价格随 `诊所.等级` 涨（D 级也贵，因为开局金钱 0）。
- 版面选「宣传诊所」→ 加名声（小额）；其余版面不加任何数值。
- 文字玩家自由写（标题 + 正文 + 署名）。
- **一期（一天）只能登一则** —— 报纸一天就出一期，这个限制天然存在，不需要额外规则。
- 当期的投稿嵌在对应版面里显示；往期的沉到「往期」折叠。

### 6.4 媚u 防线（实现时的自检）

报纸池子和 AI 供稿都要过一遍：**任何一条要是把玩家写成了世界的中心，就删掉**。
特别注意：小诊所开业第一天，报纸上不该有它的名字。

## 7. 第 4 期 · 占卜塔罗

- **22 张大阿卡纳** + 正逆位牌义，全部内置在前端（`src/sxmnq/占卜/塔罗.ts`）。
- 按 `世界.日期` 定种抽，**同一天不重抽**。
- 解读 = 牌义 × 当日局势（`精神力` / `诊所.名声` / 在诊人数）。
- 抽完**连解读一起存进变量**，当天不变：

```ts
占卜: z.object({
  已抽于: z.string().prefault(''),   // 日期戳，与 世界.日期 相等就不再抽
  牌:     z.string().prefault(''),
  逆位:   z.boolean().prefault(false),
  解读:   z.string().prefault(''),
}).prefault({}),
```

- 交互是**全屏翻牌层**：点「占卜」→ 盖一层 → 牌背 → 点开翻面 → 显出牌与解读。

## 8. 不做的事

- **不做报纸求诊/招募**。见 §2.1。
- **不做免费版面**。玩家明确否掉。
- **不把报纸内容写进提示词**。它是给人看的沉浸物，不需要 AI 知道。
- **不做玩家发帖/评论**。报纸是单向的。
- **不重构 `生成/` 那一套**。报纸的定种另起一个小 PRNG，但**不复用掷骰的池子逻辑** ——
  两者的定种键和幂等要求不同（掷骰是「日期变了重掷一批并保留已命名的」，报纸是纯派生）。
