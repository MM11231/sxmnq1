## 4. 主角

| | |
|---|---|
| **身份** | 向导学院应届毕业生 |
| **起点** | **大学毕业后，继承了这间诊所**（继承自谁不展开，留白） |
| **目标** | 让诊所声名鹊起（星级 Lv1 → Lv5） |
| **状态** | 零起点：诊所是破的、名声是零、精神力上限低 |

**为什么这个设定好用**：

1. **零起点** —— 开罗游戏的爽感全在「从一间破屋子到一栋楼」
2. **明确终点** —— 声名鹊起就是境界，不用解释「我在为什么努力」
3. **继承 = 有前史** —— 旧招牌、冲着前主人来的病人、有人记得这地方。**现成的关系钩子，白送**

## 5. 核心循环

```
接单 → 疏导（小游戏）→ 评级 → 名声 ↑ → 更高等级的哨兵上门
  ↑                                              │
  └────────── 升级诊所 ←──── 诊金 ↑ ←────────────┘
```

一天的时间线：

```
清晨  → 甩出申请列表（3–6 个候选，{{random}} 生成）
接单  → 受精神力预算限制，只能接其中几个
疏导  → 小游戏（点击清理线）
结算  → 评级 + 诊金 + 名声 + 元指令发给 LLM 写场面
夜晚  → 精神力回满、日期推进、申请列表刷新
```

## 6. 小游戏（已定稿）

### 6.1 玩法

**一个动作：点击。**

- 一束乱线随机散落在屏幕上，互相交叠
- **该点的那条一直亮着**，没有计时、不催、不闪
- 点上亮着的那条 → 线被抽走，下一条接着亮
- 点到暗着的那条 → **失误**
- 全部清完 → 结算

判定从「看位置遮挡关系」降级为「看谁在亮」—— **手机小屏幕上，发光看得清，遮挡关系看不清**。线画粗一点，手指随便戳。

### 6.2 线数

```
线数 = 污染度 ÷ 8 + (哨兵等级 − 用户等级) × 2     钳制在 [5, 25]
```

| 病例 | 线数 |
|---|---|
| 污染 60 的中度哨兵 | 7 |
| 污染 100 的重度哨兵 | 12 |
| 高玩家两级的哨兵 | 再加 4 |

系数待调，骨架如此。**难度自动调节：线多的病例本来就贵，不需要单独设计一套「难度定价」。**

### 6.3 精神力

```
精神力消耗 = 线数 + 失误次数
```

| 情形 | 消耗 |
|---|---|
| 15 条线，一根没错 | 15 |
| 15 条线，手滑 5 次 | 20 |

好在三点：

1. **算得清** —— 玩家心里有数，不是黑箱
2. **失误很轻** —— 一次 +1，不是「罚你一半财产」。但攒起来有区别，手滑十次就是白治一个人
3. **和难度天然挂钩** —— 不需要第二套定价

### 6.4 失误的三层后果

**每层都轻，叠起来才构成一个「你刚才手重了」的完整体验。**

| 层 | 内容 | 时机 |
|---|---|---|
| **即时** | 屏幕震一下，线绞紧又松开，一行短句浮现 | 当场，**本地生成，不调 LLM** |
| **数值** | 精神力 +1 | 当场 |
| **叙事** | 记进失误日志，结算时连同状态一起发给 LLM | 结算 |

**即时短句**用本地小词库随机抽，保证零延迟：

```
他闷哼了一声 / 他攥紧了床单 / 他别过脸去 / "……轻点" / 他的呼吸乱了一拍
```

**失误日志**是叙事的原料。失误不当场写，**攒着，最后一起爆发**：

> 疏导到中段的时候你手重了三次。他一次比一次安静，最后那次连闷哼都没有了，只是把脸别过去，没再看你。

### 6.5 为什么不做「成败」做「评级」

- 关系型游戏里「治死了」太沉重，玩家会读档
- 评级让玩家**永远有收获**，同时永远有「下次打更好」的动力
- 评级是**重玩价值的来源**，也是旧卡最缺的东西

**S / A / B / C** 四档，决定名声涨幅与诊金。

## 7. 经营层（四根轴）

| 轴 | 内容 | 作用 |
|---|---|---|
| **名声 / 星级** | 名声 0–100 攒满升一星，Lv1 → Lv5 | 主进度。**星级决定你能接多高等级的哨兵** |
| **设施** | 诊室等级、躺椅等级 | 诊室 = 能安全接多重的病例；躺椅 = 小游戏起始舒适度（**直接改难度**） |
| **精神力** | 每日预算，睡觉回满 | 一天能接几个 —— **稀缺资源，逼你做选择** |
| **关系** | 每个哨兵的信任 / 好感 | 跨场累积。信赖高 → 服从度高 → 小游戏更宽容 → 评级更高 |

### 7.1 名声循环

参照边境酒馆的 `基建度 0–100 → 升星 → 清零 → 再攒`：

```
名声 0–100 攒满 → 星级 +1 → 名声清零重算 → 循环
```

星级解锁（待细化，见 §12 待定 #1）：

| 星级 | 名称 | 解锁 |
|---|---|---|
| Lv1 | 无名诊所 | D 级哨兵 |
| Lv2 | 略有耳闻 | C 级、诊室升级 |
| Lv3 | 小有名气 | B 级、可收编 |
| Lv4 | 声名远播 | A 级 |
| Lv5 | **声名鹊起** | S 级、结局/自由 |

### 7.2 关系轴

信任与好感都是 0–100，**分档翻译成行为描述**（见 §8），跨场累积，永不重置。

**关键**：关系与设施 → **小游戏难度参数**。因为小游戏没有计时、线是静止的，可调的参数只有两个：

| 来源 | 改变什么 |
|---|---|
| 信赖度 / 服从度（关系） | **线数减免** —— 哨兵配合，精神力丝线更好理，最多减 3 条 |
| 躺椅等级（设施） | **失误减免** —— 起始舒适度高，每场前 N 次失误不计精神力 |

**你不是靠升级自动赢，是靠升级让游戏对你更宽容。** 手法还是要点，只是空间变大。

## 8. 结算 → LLM（核心机制）

这是从 `实习向导日记` 提取的**原理**（不照抄内容）：**不把数字丢给 LLM，把数字编译成可以直接演的行为指令。**

### 8.1 分档翻译表（示例）

| 数值 | 编译给 LLM 的话 |
|---|---|
| 信赖 ≥80 | `完全信赖{name}的能力，只愿意让{name}为自己进行精神疏导` |
| 信赖 20–40 | `对{name}的能力有一点信任，认为{name}是个正经向导` |
| 好感 ≥9 | `渴望成为{name}的恋人，会非常明显地表达出追求，非常容易吃醋` |
| 好感 3–6 | `将{name}视为有点在意的人，会时不时下意识地靠近` |
| 服从 ≥80 | `完全听从向导的指示行动，有极高的配合意愿` |
| 服从 <20 | `完全我行我素` |
| 舒适 ≥60 | `很舒服，身体的每个地方都被照顾到了的舒适感` |
| 痛苦 ≥60 | `精神海很痛，需要用理智努力压抑自己对向导的渴望才能不做出伤害向导的事情` |

**全部是行为描述，没有一个数字。** LLM 拿到的是「演什么」，不是「多少」。

### 8.2 元指令格式

```
以下为要求你编写剧情的元指令：

<info>
时间：霜降月第十二日
向导：{name}｜等级：D｜精神力：42/100
诊所：无名诊所｜名声：38/100｜星级：Lv1
</info>

<patient>
姓名：… ｜等级：C｜污染度：72
战损来源：…
</patient>

<state>
信赖度：比较信赖{name}的能力，认为{name}很可靠
好感：将{name}视为有点在意的人，会时不时下意识地靠近
服从度：大部分时间会听从向导的指示，但喜欢自己做点小动作
舒适度：有一点点舒服的感觉，想要更多的安抚
痛苦度：精神海很痛，需要用理智努力压抑自己对向导的渴望
</state>

<session>
本次疏导清理了 9 条精神力丝线，失误 3 次。
失误记录：
· 第 3 条时手重了 —— 他闷哼了一声
· 第 6 条时手重了 —— 他攥紧了床单，没出声
· 第 9 条时手重了 —— 他把脸别过去
</session>

<result>
评级：B｜诊金：+120｜名声：+4｜精神力消耗：12
</result>

请据此编写本次疏导的完整场面…
```

### 8.3 发送方式

参照日记的做法：**元指令作为 user 消息塞进聊天 → `/trigger` 触发 → AI 生成 → 界面读取回复并显示**。聊天是管道，界面是显示器。

### 10.2 界面形态：同层系统

**不用全屏 overlay**（日记那样会把正文挤掉），用**同层**（边境酒馆那样在楼层内渲染）：

- 保留聊天框，玩家仍可自由行动
- 关系型游戏需要正文，overlay 会挤掉它

```

```

## 13. 风险

| # | 风险 | 缓解 |
|---|---|---|
| R1 | 小游戏「点击亮着的」可能过于无脑，玩家三场就腻 | 先做完跑一跑，**不行再改**（用户明确认可这个节奏） |
| R2 | 元指令格式被 LLM 忽略，写出来的场面不贴合状态 | 用 `<event_trigger>` 强制语气；A/B 对比测试 |
| R3 | 每场治疗都要一次 LLM 调用，节奏可能拖沓 | 即时反馈全部本地；只有结算走 LLM |
| R4 | 名声循环太快或太慢，导致无聊或挫败 | 数值先给保守值，实测再调 |
| R5 | 同层系统在手机上的可读性 | 界面按手机优先设计，先在窄屏验证 |


**M3 单独可测**，不依赖世界书与 LLM —— 这是最先能摸到手感的一步。
